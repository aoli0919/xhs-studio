# 工作台验证记录

2026 年 10 月 7 日，本地实测环境为 macOS Apple Silicon、Python 3.14.6。新增部分为 Python 桥接和原生网页，保留上游 Go 源码和许可。

## 已验证

- 启动器下载上游 v2.5.5 官方 macOS arm64 发布文件，SHA256 与固定校验值一致；真实发布服务健康检查返回 v2.5.5。
- Python 13 项回归通过：草稿保存、恢复与删除，标题 UTF-16 计数，素材与路径校验，定时时间，可见范围映射，本地会话，提交确认，跨预览凭据与重启后的重复提交拦截，以及结果未知时的显式解除锁定。
- 真实本地服务下，浏览器完成草稿新建、自动保存、切换、刷新恢复、删除、PNG 上传、预览与移除。账号查询显示未登录。
- 演示模式的浏览器本地保存可恢复。草稿读取失败或 localStorage 损坏时编辑锁定，没有覆盖损坏数据。
- 桌面 1440 像素与手机 390 像素检查通过，手机无横向溢出。JavaScript 语法检查通过。
- 使用模拟 API 检查了发布确认快照、未知结果恢复及取消恢复操作。模拟请求没有发送到小红书。
- 默认运行目录、令牌、cookies、草稿、图片和测试输出受 Git 忽略；自定义运行目录禁止放入本仓库其他路径。

## 未验证

用户尚未扫码登录，没有发布真实笔记，没有验证定时最终发布、平台审核和对外可见性。Windows 与 Linux 的完整浏览器发布流程尚未实测。Go 源码未修改，本地未重新编译上游 Go 项目。

## 运行与检查

```bash
python3 workbench/run.py
python3 -m unittest discover -s workbench/tests -v
node --check workbench/web/app.js
```
